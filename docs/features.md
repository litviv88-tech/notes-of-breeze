# Функции

## Заметки

- Создание, правка, удаление
- Обычная заметка и список дел (чеклист, пункты вычёркиваются)
- Заголовок, тело, папка, цвет метки, закрепление
- Напоминание через WorkManager (время) и геозона (рядом с местом встречи)
- Повторы: день / неделя / месяц / год, интервал, дни недели, дата окончания
- Место встречи: адрес, текущая точка, карта
- Вложения: фото и видео, текст с фото для поиска
- Поиск по заголовку, тексту, месту и OCR картинки
- Свайп для удаления на списке

## Папки

- Создание, переименование, удаление, счётчик заметок
- Ярлык: цвет, фото или живое видео до 10 секунд
- Видео-ярлык обрезается в приложении и зацикливается на обложке
- Перемещение заметок между папками

## Виджеты (Glance)

Каждый экземпляр хранит свой `WidgetConfig` в Room:

- Размер от `1×2` до `6×5` клеток, с живым предпросмотром
- Подгонка фото под выбранный размер: перетаскивание и масштаб
- Источник: все заметки / папка / одна заметка
- Фон из галереи и прозрачность 0–100%
- Цвет текста, размер шрифта 10–24 sp
- Режимы: `TITLE` / `FULL` / `CHECKLIST`
- Число заметок 1–5, скругление 0–32 dp
- Тап открывает `MainActivity`

## Внешний вид

Одна готовая палитра:

| Id | Цвет |
| --- | --- |
| Breez Blue | `#4A90E2` |

Плюс свой цвет через HSV-пикер.

Светлая / тёмная тема переключается отдельной кнопкой на главном экране.  
Material You — переключатель на API 31+.

Обои главного экрана: 12 встроенных градиентов, фото, сплошной цвет, затемнение 0–80%, размытие 0–25 dp.
