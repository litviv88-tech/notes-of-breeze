# Главный экран

Порядок блоков сверху вниз фиксирован. Не менять последовательность и не убирать обновление вниз экрана.

1. **Заметки** — обычные заметки, создание сверху (`+`).
2. **Создать список дел** — чеклист, пункты вычёркиваются.
3. **Создать папку** — в папке лежат и заметки, и списки дел.
4. **Внешний вид, обои, светлая/тёмная тема**.
5. **В самом низу** — какая версия стоит, какая вышла, обновление из приложения.

То же правило действует в веб-версии на GitHub Pages.
